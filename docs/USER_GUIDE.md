# 使用指南

## 曲库与演奏

启动后从曲库选择曲目；演奏页不自动打开任何曲目。《你离开的事实》在内置曲目中，按需打开。
演奏设置中的“深色演奏模式”独立于应用主题；默认深色背景、白色琴谱。
简谱保持上下两行和大括号，不显示左右手文字；增加了八度点、减时线及变化标记的留白。


在“曲库”选择 MIDI / MusicXML 文件，或打开内置练习。导入后文件保存在应用中，无需每次重新寻找原文件。曲目可重命名、删除；退出演奏或暂停时保存练习位置，跟谱中定期保存位置。

进入“演奏”后点按谱面选择起点。演奏设置中可选麦克风或 USB MIDI、参与跟谱的音轨、高低音谱表，以及逐行 / 分页模式。点击“开始跟谱”后再弹奏。

默认从所选位置跟随。开启“自动定位起弹位置”后，应用在整首曲子中等待一段可区分的音符序列；重复乐句可能需要多弹几音。显示“失配”时可继续演奏，或直接点按新的起点。

手动滚动或翻页会暂停自动移动，点击“回到跟随位置”恢复。专注模式隐藏主导航栏，退出专注模式后可切换曲库或其他功能。旋转屏幕后保持音乐位置。

播放按钮用于示范播放。首次点击才加载音源；加载失败可重试。开始听音跟谱会暂停示范，避免麦克风识别应用自己发出的声音。

## 原声钢琴

允许麦克风权限，选择麦克风输入，先让应用听到房间背景声再开始演奏。输入设置中可查看电平及采样率。如果钢琴整体偏离标准音高，可先到“校音”按提示弹中央 C，再返回演奏。

本预览版在部分快速、装饰音或复杂复调片段中仍会失配或错误重新定位；固定回归和未见曲目的成绩不同，尚未达到完整验收。请参考测试报告中的实际结果。听音试用时可在演奏设置关闭“自动移动谱面”，仅观察位置；MIDI 模式与听音模式的验证结果分别报告。

## USB MIDI

通过支持数据传输的 USB / OTG 连接电钢琴，琴应提供 MIDI 数据。单个可用设备自动连接，多个设备在设置中选端口。在“录制”页面能直接看到当前琴键与音名；跟谱时需要在演奏设置中选择 USB MIDI 输入。

设备断开时依赖 MIDI 的跟谱或录制会暂停，已有录制会保存。模拟器注入测试通过不能证明你的琴与手机已实际兼容。

## 录制与基础记谱

1. 连接 MIDI 键盘，在“录制”设置速度、拍号、调号与量化精度。
2. 点击“开始录制”，演奏后“停止并保存”。
3. 用回放按钮听原始演奏；“琴谱”打开派生五线谱。
4. “MIDI”导出保留原始时间、力度、通道和踏板的文件；“五线谱”导出 MusicXML。
5. 可重命名、删除录制，或调整量化设置后重新生成琴谱。原始事件不会因量化而被覆盖。

每次录制最多一小时或 50 万条事件，达到限制后自动停止并保存；约每三秒保存一次已有事件。自动谱表分配和节奏量化是基础功能。需要逐音符编辑或精细排版时，可把 MusicXML 导入其他乐谱编辑器。

## PDF 与照片

从曲库导入 PDF / 图片或从相册多选照片。PDF 会转换为多页图片，之后可管理页序、删除、设置全曲时长、开始滚动与暂停。页面和滚动位置保存在应用中。

图片滚动按设置时长工作，不会听音判断你弹到了哪里。图片识谱不在本次范围内。

## 安装与数据

Debug 测试包可与原应用并存，应用 ID 为 `com.pianoscorefollower.app.debug`。Release 使用原应用 ID；覆盖安装必须与原包使用相同签名。卸载应用会删除其私有曲库与录制，请先导出重要 MIDI / MusicXML。

旧版谱面会迁入曲库并保留旧文件。旧版已经丢失的 MIDI 原始字节无法恢复；图片索引与外观设置继续使用。


## 全屏看谱与简谱

演奏页直接铺满琴谱，系统状态栏与底部导航默认收起。底部悬浮条提供返回曲库、开始 / 暂停、演奏设置与隐藏工具栏；平板同时显示前后页。点按隐藏按钮后只留右上角“显示工具栏”，显示与隐藏不改变谱面排版。系统返回键先关闭设置或退出隐藏状态，再返回曲库。

在“演奏设置”面板切换“五线谱 / 简谱”，当前音乐位置不变。简谱每个谱行上排右手、下排左手，左侧大括号连接；小节线与同时触键的拍点对齐，多个小节连续横排，按屏幕宽度换行。同一只手有多声部时保留其独立节奏；和弦上下叠放，低音和高音用八度点标记。小调使用关系大调的 1 标记，非标准时值显示实际拍数；它是练习视图，不是完整出版排谱。点按简谱触键可选起点。PDF / 照片仍使用原图显示。

## 音高与节奏评分

在演奏设置切换“评分练习”，选择权重与练习速度，关闭面板后点“开始评分”。评分从选定触键起到曲末，关闭自动寻找起点。首次命中曲谱音符确定计时起点，此后按曲谱速度变化及所选速度评估；实际演奏中的停顿会影响节奏分，点按暂停或后台中断会暂停计时。

设总应弹音数为 N。每个和弦音分别占一个位置；同一时刻同音高的重叠声部按一个物理琴键计，休止和延音续音不计；反复中再次触键会再次计数。正确音获得音高分，错音或漏音不获得音高分；错音替代一个应弹位置，不再重复算一次漏音。错音仍可获得对应节奏分，多弹的音额外扣 100/N 分。

节奏误差在 ¼ 拍内得满分，¼ 到 ½ 拍线性下降，达到 ½ 拍得零分。默认总分 = 70%×音高分 + 30%×节奏分 − 多弹扣分，限制在 0–100 分。权重和练习速度可调整。只有明确点按“结束并评分”后才将后续未弹的音计为漏音；“重新评分”从头新建一轮，已评分段落回头重弹不会重复加分。

当前分数入口位于右上角小标签，点按后打开面板，可结束练习并查看错漏音、节奏误差（毫秒），点击明细跳回该音乐位置。评分结果保留在当前应用会话中；修改起点、声部、输入或评分设置会重建评分。麦克风受踏板、泛音与定位不确定性影响，结果标注“听音估算”，待确认部分显示分数范围；精确逐音检查优先用 MIDI。录音定位测试不能证明逐音评分的声学准确率。


## 连贯跟随与回头重弹

光标优先按当前谱面路径跟进，零星错音时保留原位置附近的候选。小范围音符位置允许校正；自动移动谱面使用确认锚点，跨行小回移要稳定约 0.65 秒，减少来回翻动。需要回头或跳段时，请继续弹出几个连续音，位置确认后会一次移到新段；候选仍不确定时暂停自动翻页。刚跳转又立即反向需要更多音符确认。正常反复不受此限制。点按谱面选择新起点会立即清除惯性，不必等待自动确认。确认机制可能略晚于首个重新起弹音，这是稳定显示与快速跳转之间的取舍。
