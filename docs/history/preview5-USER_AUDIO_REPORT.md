# 《你离开的事实》用户音源实测

日期：2026-11-01；应用：1.0.0-preview.4 / versionCode 16。

**已执行完整软件管线回放，尚不宣称全曲跟准。** 视频没有逐音 / 小节真值，下面是行为诊断，不能当作定位正确率或评分准确率。

## 输入与方法

用户提供原始 MP4，时长约 228.414 秒，AAC 立体声 44100Hz。原文件只读，未修改、未打包进应用。视频 SHA-256：`5123a2d36509543940372b40de5f520ce63092aca8b6000cea54772ceb56e625`。

使用项目内 `the_truth_that_you_leave.mid`，经 Android 同一 `MidiToMusicXml` 转换，再用实际 `graph.js` 导出模型。内置 MIDI 约 216 秒、116 小节；演奏速度与编配未逐小节人工核对。转换后 PCM 单声道 44100Hz，前置三秒静音，1024样本一帧依次送入实际 AudioAnalyzer / OnlineAligner，不读取未来声音帮助跟谱。

## 完整回放结果

- 已处理约 228.410 秒源音频（最后不足一帧不参与处理）。
- 最终版本没有超过两拍的大幅回退；小范围位置 / 节奏校正保留。
- 第一版惯性候选约38.75–116.86秒曾持续不推进；最终版本已消除此故障。
- 约165.51–169.94秒仍有约4.4秒不推进，期间分析器仍检测到起音，需进一步处理密集声部 / 编配差异。不能把该区间算成跟准。
- 最后音的尾声保持不推进属于单独诊断区间，不与中段失配混为一谈。

## MuMu 应用内回放

Debug 将同一份解码 PCM 直接送进实际分析与跟谱管线，完整文件从头运行到尾；未播放声音给模拟麦克风，未将注入当成手机收音实测。

另一次从曲头开始约33秒的窗口采集94个页面状态，没有反向换行。完整文件回放期间连续采样约233秒、688个页面状态，观测到0次反向换行；后者采样开始时位置已到27840附近（首次采样tick为28319），因此不据此声称该窗口逐帧覆盖了最初几秒。两份原始采样记录均保留。完整回放结束时tick441359、确认锚点441120、谱行37，应用正常运行。

这个结果证明实际应用链路与导航惯性运行；不能证明所有音符位置都正确，也不证明实体手机麦克风或USB硬件通过。

## 仍需处理

中段约4.4秒停留；更多演奏版本的兼容性；人工小节锚点与真实声学验证。通用恢复回归仍只有18/20在三秒内恢复，完整验收未通过。

## 复现

先构建 Debug Kotlin 类；用 `tools/ConvertScore.java` 调用实际转换器生成 MusicXML，再用 `tools/export-graph.cjs` 导出 graph.tsv。用ffmpeg将用户视频转成44100Hz单声道f32le并前置三秒静音，生成清单后通过 AudioBenchmarkTest 执行。无真值的用户音频使用 `tools/report-user-audio.py`，不要调用正确率工具伪造精确度。详细命令见 [TESTING.md](TESTING.md)。
