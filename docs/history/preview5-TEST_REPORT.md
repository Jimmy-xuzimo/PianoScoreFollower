日期：2026-11-01。版本：1.0.0-preview.4（versionCode 16）。

## 方法与数据边界

- JDK 17、Gradle 8.9、Android SDK / Build Tools 36；MuMu Android 15。
- [Matchmaker 数据](https://github.com/pymatchmaker/matchmaker-benchmark-data/tree/7ea5babf039a0c009050646c90ea2bfe925653f6)，固定版本 `7ea5babf039a0c009050646c90ea2bfe925653f6`。
- ASAP / Batik / Vienna 共九条开发、九条固定回归；BWV891 / KV281 另外五条原独立录音。本次这些数据都作为回归检查，不声称又获得一次独立泛化测试。
- 完整文件转为 44.1kHz 单声道，前置三秒静音，每 1024 样本送入实际 AudioAnalyzer / OnlineAligner，严格按时间顺序处理，不用未来音频帮助定位。
- 真值只用于事后误差统计；按首尾有效标注之间时间加权，包含失配与低置信度，不包含未标注尾音。半拍指 0.5 四分音符。
- 数据、原谱、音源、用户视频在源码之外，保留原数据来源与许可，不装入 APK 和源码包。

## 连贯跟随修改与诊断

- 不连续位置须由连续推进的音符证据确认，单个保持音不增加计数；明显停顿后重新起弹复用已有序列证据。连续演奏中跨超过 16 拍的跳转采用更长确认，刚跳转再反向也需更多证据。
- 局部匹配可靠时优先沿当前谱面路径，失配时保留原位置附近的候选；位置先验随持续失配衰减，避免一直卡在旧位置。
- 两拍以内的局部校准保留，避免慢速长音的正确位置被强行顶在前面。行与分页由确认锚点驱动，跨行小回移持续 650ms 后才移动视口，点按起点立即生效。
- 23 条正常录音的原始 tick 回退次数为 503→488，超过半拍的回退 64→52，超过八拍的前跳 5→2。它们包括正常节奏校正，**不是错误翻页次数或正确率**；不能用单向锁死光标冒充更稳定。
- 曾测试过强行单向锁光标的候选版，导致慢速段落明显退步；该实现已撤销，当前三条受影响录音恢复到约 92%、96%、90%。失败候选未混入最终构建。

## 用户提供的《你离开的事实》

完整视频音轨约 228.414 秒，AAC 立体声 44100Hz。使用项目内同曲 MIDI，经实际 MidiToMusicXml 转换后跟随。首轮惯性候选在约 38.75–116.86 秒出现长时间停留；最终版本已消除此问题，完整回放没有超过两拍的大幅回跳。小范围节奏与位置校正仍保留。

约 165.51–169.94 秒仍存在约 4.4 秒不推进，需要继续核对编配与密集音型。这段视频没有人工小节 / 音符真值，**不报告“定位准确率”或评分正确率**。原始视频不修改、不打包进应用。

详见 `USER_AUDIO_REPORT.md` 与用户音频诊断 JSON。模拟器直接注入解码 PCM，验证应用管线与页面移动，不能替代真实手机麦克风声学测试。

## MuMu 实际操作

以下包含系统文件选择器操作与 Debug 注入检查，未把模拟器注入当成 USB 硬件连接。

- 曲库导入、打开多曲目；保存后重启恢复。
- MIDI 录制后生成谱面，导出 MIDI 与 MusicXML；Android 播放器打开原始 MIDI，进入运行状态。
- 压缩 MXL 实际打开，128 个事件；损坏 XML 提示错误，应用保持运行。
- 修正内置 C 大调练习原文件缺少左手 `backup` 的问题；双手事件为 128 个，均在实际小节范围内。
- 从起点注入 72 个触键事件，原生位置与网页光标均到 **68160 tick / 第 18 小节**，置信度 0.9；页面实际前进。
- 横竖屏切换后 tick 仍为 68160；手动翻页显示“回到跟随位置”，点击后回到当前光标。
- 真实 Bach 录音前 23 秒通过 Debug PCM 注入：约 5 秒为 1919 tick，12 秒为 7763 tick，结束为 17986 tick；与 JVM 同管线输出对应。此检查验证 Android 执行链路，不验证手机麦克风声学效果。
- 麦克风权限拒绝后反馈、再次允许、实际 44100 Hz 输入启动；示范播放与收音跟谱互斥。
- 本地音源按需加载后示范可播放；重建播放器后等待实际合成器就绪再请求音源，重试成功并保留 15360 tick；示范播放暂停后保存为 19200 tick，返回页面恢复该音乐位置。
- PDF 实际通过系统选择器导入为两页；可定时滚动、暂停；页面顺序从 `1,2` 改为 `2,1`，磁盘索引同步；重启保留页面与位置。
- 旧版 XML / 元数据样本迁入曲库后，旧 `score/current.bin` / `current.meta` 仍存在。图片页序索引首次读取时另存 `index.legacy-v1.bak`。旧版未保留的原始 MIDI 不伪造恢复。
- Release 清单不包含测试广播入口，不启用 WebView 调试。



上列文件 / 录制检查来自重建期间多轮实际操作；本次 preview.4 重点复测跟谱、用户音源与页面导航，没有把历史操作描述为每个版本均重新全量执行。

## 简谱与演奏界面

参考 [Everyone Piano 双手简谱实例](https://tw.everyonepiano.com/Number-1701-1.html)，仅参考排版结构，不使用其乐曲或图片。上排右手、下排左手，左侧大括号，小节与拍点对齐，连续谱行按屏幕宽度换行。八度点竖排，长音数字位于实际起音列，延长横线位于后续拍点。

原生操作使用 Google 官方 Compose Material 3。琴谱全屏，窄悬浮条可隐藏；设置 / 评分在 ModalBottomSheet，不挤压琴谱。横竖屏和切谱保留 68160 tick；五线谱、简谱与暂停 / 返回的导航锚点历史分别正确清理。

评分仍为当前会话数据：默认音高70% / 节奏30%，每个应弹音等权，反复重复计，休止与延音续音不计。麦克风逐音评分是估算，尚无带逐音错漏标签的真实音频评分验收，不能以位置测试代替评分验收。
